# ISI School Exercise Repository

This repository is organized under the main folder named:

`Development of Advanced Web Applications`

Each exercise project is kept separate in its own folder inside this parent directory so the work stays clean, structured, and easy to follow for the teacher.

## Structure

```text
isi-school-exercises/
├── README.md
├── Development of Advanced Web Applications/
│   ├── README.md
│   ├── Exercise_01_SpringBoot/
│   │   └── README.md
│   ├── Exercise_02_Angular/
│   │   └── README.md
│   └── Exercise_03_FullStack/
│       └── README.md
└── ...
```

## Notes

- Each exercise is isolated in its own folder.
- The parent folder is the main organization unit for the course.
- You can add project files, source code, documentation, and screenshots inside each exercise folder.
