# ISI School Exercise Repository

This repository is organized under several main course folders, including:

- `Development of Advanced Web Applications`
- `Advanced Databases`
- `Programmation Python Avancée`
- `Network protocols and services`

Each exercise project is kept separate in its own folder inside its course directory so the work stays clean, structured, and easy to follow for the teacher.

```text

├── README.md

└── ...
```

## Notes

- Each exercise is isolated in its own folder.
- The course directory is the main organization unit for each subject.
- You can add project files, source code, documentation, and screenshots inside each exercise folder.
